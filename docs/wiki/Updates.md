# 版本与更新

## 安装版本

镜像在 [GitHub Packages](https://github.com/Wzh0718/gcl2api-plus/packages) 发布，镜像名为：

```text
ghcr.io/wzh0718/gcl2api-plus
```

请核对实际标签和对应提交，不要仅依据提交活跃度判断镜像已经更新。

## 更新频率

README 提供 `dev` 分支最近提交与每月提交活跃度徽章。徽章可能缓存；统计的是代码提交，不是镜像发布次数。本项目没有固定发布周期承诺。

开发变更先向 `dev` 提交 PR，经过验证后再由 `dev` 晋级到 `custom`。正式发布使用晋级后的提交。

## 新版面板版本提示

顶部版本区域链接到本仓库 Packages。检测明确返回版本不同时显示小红点；检测失败或无法确定时不显示。

当前比较来源是 `custom` 分支的 `version.txt`，不是 GHCR 镜像摘要，也不是语义版本大小比较。文件未及时更新、网络失败或 GitHub 限制都可能影响提示；红点消失并不能证明运行镜像一定最新。

## 部署更新

按项目现有 Compose 部署更新时，先拉取目标镜像并将 `gcli2api` 服务指向目标标签，然后执行：

```bash
docker compose up -d --no-deps gcli2api
```

启动后核对运行镜像和容器健康状态。详细部署参数见所安装提交的 README 与开发发布指南。

## 页面仍是旧样式

确认运行镜像版本后刷新页面，必要时强制刷新以重新加载脚本和样式。浏览器主题偏好与服务版本是两回事。
