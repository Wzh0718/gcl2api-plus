# 密钥分发

> 本页描述 [PR #141](https://github.com/Wzh0718/gcl2api-plus/pull/141) 的新版界面，尚未发布。

## 查找密钥

搜索框支持名称、密钥前缀、账号和模型，也可以粘贴完整独立密钥做精确匹配，再通过状态筛选定位目标。

完整密钥通过面板认证保护的 POST 请求检索，不放入 URL。服务端校验密钥哈希，只返回匹配记录 ID；此检索不会把停用或吊销的密钥恢复为可调用状态。

清除筛选后恢复列表。批量选择只针对当前筛选结果，每次最多 100 把。

## 创建

1. 点击右上角“创建密钥”。
2. 填写名称；按需设置金额额度、重置方式、到期时间、绑定账号、提示词融合及允许模型。
3. 点击“创建密钥”。成功后弹窗关闭，列表刷新。
4. 在列表点击“复制密钥”，再将密钥配置给调用方。

额度留空表示不限额。页面顶部保留 OpenAI、Claude、Gemini 三种 API 地址，点击地址即可复制。

## 管理

点击目标密钥的“管理设置”，在弹窗中调整参数并点击“保存设置”。保存成功后关闭弹窗并刷新列表；失败时显示原因并保留输入内容。

“停用 / 启用”和“复制密钥”直接显示在卡片上。停用密钥保留管理记录；吊销属于不同操作，位于管理设置中。环境配置密钥保持只读兼容入口。

绑定账号、模型限制、限流和可用状态共同决定请求是否可执行；“列表中能找到”不代表“允许调用”。

## 批量限流

1. 勾选目标密钥，或在弹窗内选择当前结果。
2. 点击“批量限流设置”。
3. 填写各时段限流参数，确认已选数量。
4. 点击“保存到所选密钥”。

未选择密钥或超过数量限制时不能提交。保存失败后可修正重试；关闭弹窗不会提交修改。
