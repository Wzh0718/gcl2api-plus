# 控制台与主题

> 本页描述 [PR #141](https://github.com/Wzh0718/gcl2api-plus/pull/141) 的新版控制台，尚未发布。

## 页面导航

| 模块 | 用途 |
| --- | --- |
| 密钥分发 | 为调用方创建独立密钥，管理额度、模型、绑定账号与限流 |
| Antigravity 认证 | 登录授权或导入 Refresh Token |
| 凭证上传 | 上传凭证文件 |
| 凭证管理 | 查看和管理账号凭证、代理、用量和状态 |
| 调用统计 | 按账号、模型等条件查看统计 |
| 调用监控 | 按账号、API Key 或实时请求查看记录 |
| Token 计费 | 查看所选周期的用量、费用、趋势和排行 |
| 配置管理 | 调整服务器、兼容性、提示词和采集等设置 |
| 实时日志 | 查看服务日志 |

## Light / Dark

右上角太阳图标切换浅色，月亮图标切换深色。首次进入时跟随系统主题；手动选择后记住该浏览器的偏好。同一站点的其他标签页会同步偏好。浏览器禁止本地存储时仍能切换，但刷新后可能不保留。

深色配色参考 One Dark Pro Night Flat。常规操作使用蓝色强调；成功和失败分别使用绿色、红色。普通按钮采用描边，选中项有明显状态区别。

## 设置弹窗

密钥创建、管理和批量限流在弹窗中完成。可以使用“关闭”或 Esc 退出；小屏幕上可在弹窗内滚动。保存期间按钮禁用，失败时保留内容供修正和重试。关闭弹窗本身不会保存。

配置管理中的“设置”按钮当前仍是就地展开详细参数，与密钥弹窗不同。

## 本地设计预览

开发者可在仓库目录执行：

```bash
python3 scripts/ui_preview/server.py --port 18761
```

访问 `http://127.0.0.1:18761/`，移动端预览访问 `/mobile`。预览使用浏览器内的演示数据，刷新后恢复，不执行真实授权、凭证导入或生产操作。
