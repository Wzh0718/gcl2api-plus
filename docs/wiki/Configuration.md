# 配置管理

## 设置在哪里

| 一级分类 | 主要内容 |
| --- | --- |
| 基础设置 | 服务器配置、凭证目录、远程图片内联、端点配置 |
| 网络代理 | 代理组与节点导入 |
| 凭证与重试 | 凭证及重试相关参数 |
| 兼容与模型 | 兼容性开关、模型与版本、请求节奏、容量、额度保护和抗截断 |
| 内容与提示 | 提示词与内容处理 |
| 保活与告警 | 保活 URL、间隔和告警 |
| 监控与采集 | 调用记录保留、请求证据采集及导出 |

“凭证目录”和“远程图片内联”已合入“服务器配置”；“端点配置”同属基础设置。

## 兼容性配置

主页面保留常用开关，其他参数通过六个“设置”入口展开：账号复检、模型与客户端版本、请求节奏、全局容量与休眠、账号用量与额度保护、输出抗截断。摘要显示当前开关与参数配置情况。

桌面左右两栏，手机单栏。展开或收起不改变保存的配置；修改后仍需点击页面顶部“保存更改”。

## 保存反馈

- 修改后提示“有未保存的更改”。
- 提交时显示“保存中…”，避免重复点击。
- 成功后显示保存成功；需要重启的配置会另有提醒。
- 参数验证失败会展开相应设置；网络或服务失败会提示重试。

环境变量锁定的字段仍由后端配置优先级管理，界面调整不解除锁定。

## 全局代理变化

**新版面板移除了全局代理输入入口；保存配置时会写入 `proxy: ''`，清除主库中的原全局代理设置。** 依赖该值的部署应先确认账号代理或代理组配置，再保存。环境变量的优先级仍然有效。

仅回退页面代码不会恢复已经清空的代理值，需要按部署原值重新配置。

## 保活、监控与采集

“一键设置保活”用于填写保活地址，之后保存配置。请求证据采集的容量和保留策略在“监控与采集”中设置；“刷新容量与丢弃状态”读取当前状态，“下载证据包”按采集 ID 或凭证文件名导出。演示环境不能替代真实采集和导出验证。
