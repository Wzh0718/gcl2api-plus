# 监控与计费

## 调用监控

- **账号**：按账号查看调用表现。
- **API Key**：按密钥分组，可展开查看账号明细，支持展开全部、收起全部。
- **实时**：逐条查看请求记录及可用的请求详情。

成功率、状态、用量、费用和耗时的口径不同，不应把成功率当作额度使用率。深色模式下分组行、子行和状态标签均使用对应主题。

## Token 计费周期

每日趋势与页面当前选择的周期一致：

| 选择 | 趋势范围 |
| --- | --- |
| 当天 | 当天已有账单记录 |
| 7 天 | 近 7 天范围内的记录 |
| 14 天 | 近 14 天范围内的记录 |
| 30 天 | 近 30 天范围内的记录 |

当天只有一个账单日时，图上显示单个点，不补成 7 天。无数据时显示空状态。实际显示的账单日数量取决于接口返回的数据，不保证每天都有记录。

每日趋势上方显示累计用量、单日峰值和累计费用。折线表示 Token 用量；费用不共用 Token 纵轴，具体数值见“每日明细”。

选择某把密钥后，默认查看其当前额度周期，与密钥管理中的额度一致。额度周期视图不伪造按日明细；需要分类趋势时切换当天、7 天、14 天或 30 天。

快速切换周期时，以最后一次选择为准，旧请求结果不会覆盖新周期。

## 查看错误

如果出现“加载调用监控失败”，保留错误文字、所选视图和发生步骤再反馈。遇到脚本变量未定义等前端错误时，先刷新页面加载当前版本脚本；若仍复现，请附上服务版本和完整报错。
