# 按 API Key 绑定账号

在“密钥分发”中创建或编辑托管 Key，通过 **绑定账号** 下拉框选择已经导入的 Antigravity 账号，保存即可。每个 Key 只绑定一个账号，Gemini 和 Claude 共用；选择“不绑定，使用凭证池”并保存后恢复凭证池。账号选项显示邮箱和凭证文件名，停用账号有明确标记，已删除的历史绑定会保留并标记，不会自动清空。

每个 Key 独立保存一个绑定。为兼容旧数据及调用方，存储和 API 继续使用历史字段名 `claude_credential_name`，现在对 Gemini 和 Claude 均生效。该项也可在面板认证保护下通过 `POST /api-keys` 创建，或 `PATCH /api-keys/{id}` 修改；JSON 例如：

```json
{"claude_credential_name":"ag_example.json"}
```

空字符串或 null 表示解除绑定。非法路径或不存在的凭证会被拒绝。环境配置密钥保持只读；需要账号绑定时创建托管 Key。

绑定作用于通过 Antigravity 通道发起的 Gemini 和 Claude 请求（包括 Gemini 图片请求），涵盖 OpenAI Chat/Responses、Anthropic Messages 和 Gemini 协议，以及流式、非流式、假流式与续传路径。未绑定的 Key 和环境配置密钥继续使用原来的凭证池。保留原始 Claude 意图的参数只在网关内部传递，不会发给模型；因此现有会被映射成 Gemini 的 Haiku 别名请求也遵守原 Claude 账号绑定。

## 不可用与重试

- 绑定是严格限制，不是“优先使用”。账号停用、模型冷却、删除、token 刷新失败、代理或健康门禁不通过时，不会改用其他账号。
- 并发和排队规则继续执行。账号繁忙时按既有等待/错误策略处理；不会绕过并发限制。
- 重试、预取下一个凭证及原有模型降级链都受同一个账号限制；不会因换模型逃到其他账号，图片请求同样只从绑定账号申请图片任务槽位，遵守原有容量与并发规则。
- 一个请求只读取一次绑定快照。修改配置从下一请求生效，当前流和重试继续使用原账号；不同 Key、异步任务之间不共享绑定。
- 绑定账号不可用时返回原有错误或“无可用凭证”；绑定本身不解除封禁，也不额外发起账号探测。

## 与 NewAPI 的关系

这里识别的是 **gcli 实际收到的 API Key**。如果 NewAPI 多个用户共用同一个 gcli 上游 Key，它们会共用该 Key 的账号绑定。要区分用户，需让不同用户/渠道使用不同的 gcli 托管 Key。客户端请求体不能自行覆盖账号绑定。

## 存储与验证

SQLite 启动时自动为旧 api_keys 表补充 `claude_credential_name`，默认空字符串；原有非空绑定保留，并统一应用于 Gemini 和 Claude。绑定以凭证文件名保存；删除凭证后保留绑定并明确失败，避免意外切换账号。

离线测试覆盖独立 Key、保存/更新/清空、旧库迁移、不可用账号、重试快照、模型别名、流式任务交接和关闭。未执行真实模型请求，未修改生产配置或部署。

账号候选接口 `GET /api-keys/accounts` 需要面板认证，仅返回文件名、邮箱和停用标记，不包含 token 或代理信息；响应禁止缓存。列表加载失败时禁用账号选择并保留当前绑定，可点击页面刷新重试。

本次验证：关闭本地私有环境的原生传输默认开关后，全量离线回归 1041 项通过；桌面和手机版在 320、768、1024、1440 像素下完成创建、修改、解除绑定及账号列表失败恢复验证。Python 编译、JavaScript 语法和差异检查通过。未部署生产服务。
