# 客户端 System 侧载选项

在桌面版或手机版控制面板的「客户端提示词」中配置，保存后生效。仅作用于 Antigravity 通道，默认关闭。

## 混淆方案（三选一）

| 方案 | 行为 |
| --- | --- |
| 关闭（off） | 不混淆 |
| 全文 Leet（full） | 原方案：`a/e/i/o/u → 4/3/1/0/v`，大写对应 `4/3/1/0/V`；代码、路径、字段等也会改变 |
| 智能保护 Leet（protected） | 保护精确内容，仅混淆剩余文本，附加原文解码说明 |

旧配置 `antigravity_system_vowel_obfuscation_enabled=true` 自动对应全文 Leet，不会自动切换智能方案。新面板保存混淆方案时同时更新旧布尔键；旧客户端只提交布尔值时仍可开启全文或关闭混淆。

### 智能保护范围

- 保留 Markdown 代码块（包括未闭合的代码块）、行内代码、引号内容、有效 JSON 对象/数组。
- 保留路径、URL、文件名、snake_case、camelCase、大写常量、命令行长选项和环境变量引用。
- 保留 `Return only…`、`Reply exactly…` 等明确的输出约束语句，减少格式要求在编码后被弱化的情况。
- 从实际工具定义中提取工具名称、参数名和字符串枚举值并保留。工具定义本身不改变。
- 保留常见环境 XML 块及工具/环境 Markdown 章节；根据客户端结构扩展保护相应章节。
- 精确数据片段用不会与原文冲突的 `<gcli_literal>`（必要时加后缀）边界包裹；解码说明要求模型逐字保留这些内容，遵守原有输出格式，不额外解释编码。输出约束语句保持原文指令，不包成数据标签，以免模型将约束当作需要引用的数据。

这不是通用语法分析器。自动规则可能遗漏无标记的精确词，例如普通英文 `status` 既可能是自然语言，也可能是字段名。需要精确匹配的内容建议用反引号、引号或代码块明确标记。JSON 识别最多尝试 128 个候选起点，每次最多使用 512 个工具相关精确词，以限制异常输入的处理成本。

### 客户端识别

识别发生在敏感词替换前，结合身份声明和另一项结构信号，避免仅因正文提及客户端名称就命中。支持 Codex、Claude Code、DSH、Pi 的启发式结构规则，未命中则使用通用保护。识别结果不改变请求权限或提示词优先级。

DSH、Pi 等规则当前基于显式身份/结构样例，不能声称兼容这些客户端的所有真实版本。解析后的客户端文本仍经过现有敏感词过滤，智能保护只保证所识别片段不被 **Leet** 转换，不撤销敏感词规则已做的修改。

### 预览

预览默认折叠，处理后文本与附加解码说明分开展示。点击生成后发送到本服务试算，复用相同编码函数，不保存内容、不调用模型。仅处理输入文本，不叠加敏感词规则、请求工具定义、角色转换或提示词融合。输出通过 textContent 显示。

## 客户端 System 转 User（独立开关）

将协议转换后的客户端系统提示放入会话开头的 user 消息，附加“先阅读并理解提示词，再处理后续任务，无需额外回复确认”的引导。空提示词不添加引导。是否遵守仍由模型决定，指导保持 user 优先级。

与智能方案同时启用时，解码说明和编码后的客户端提示一起放入该 user 消息。启用任一混淆方案或 System 转 User 时，AGY 转换入口先保留 system，避免兼容模式提前将其混入普通用户任务。原始 system 消息可能已被协议转换器合并；后续非连续 system/developer 消息仍遵循现有协议转换规则。

## 处理顺序与组合

原始客户端 system → 识别客户端 → 现有敏感词过滤 → 选定混淆方案 → 按需转为 user → 注入服务端基础提示/前置文本。普通用户对话、工具定义、调用和结果不参与混淆；服务端提示、引导和解码说明也不参与混淆。

提示词融合成功时优先于侧载选项，使用保留的客户端原文生成新的 system 指导；失败时保留侧载结果。所有混淆方案均不使用插字或零宽字符，不保证减少 429 或避免后续 403。

## 配置

| 配置键 | 环境变量 | 默认值 |
| --- | --- | --- |
| `antigravity_system_obfuscation_mode` | `ANTIGRAVITY_SYSTEM_OBFUSCATION_MODE` | `off` |
| `antigravity_system_vowel_obfuscation_enabled`（旧键） | `ANTIGRAVITY_SYSTEM_VOWEL_OBFUSCATION_ENABLED` | `false` |
| `antigravity_system_as_user_enabled` | `ANTIGRAVITY_SYSTEM_AS_USER_ENABLED` | `false` |

混淆方案读取顺序：新环境变量 → 旧环境变量 → 已保存的新方案 → 已保存的旧布尔值。环境变量控制时界面锁定对应设置。无效的新方案环境变量按关闭处理；面板 API 拒绝无效方案。
