# AGY 提示词融合

在「系统 · 配置管理 → 内容与提示 → AGY 提示词融合」设置：

- **全局开启**：为没有账号覆盖设置的 Antigravity 账号开启融合，默认关闭。
- **账号设置**：到「账号管理 → 凭证管理」，点击对应账号的「提示词融合」，设置「跟随全局 / 单独开启 / 单独关闭」，保存后生效。账号覆盖优先于全局值；关闭全局不会关闭显式单独开启的账号。
- 账号设置读取失败时禁止保存，已有设置保留；单账号保存只更新该账号，不覆盖其它账号。配置管理只保存全局开关。

网关选中账号后，使用该账号和本次请求的文本模型做一次额外模型调用。绑定 API Key 时使用绑定账号；使用凭证池时使用实际选中的账号，不为优化另行选账号。复用其认证和代理，并受账号并发和节奏控制约束。无需配置额外 API Key。适用于 Gemini / Claude 文本请求；图片请求、非纯文本系统指导、空指导及超过 128 KiB 的优化输入跳过融合。

## 内容与已有开关

优化器仅接收客户端系统指导、实际工具定义、网关自定义提示、AGY 固定基础模块及环境适配说明。用户任务和聊天历史不参与优化，不写入优化缓存。输出为融合后的客户端指导；网关在 system 中组合「原样网关前置文本 + AGY 基础模块 + 适配说明 + 客户端指导」。工具定义、历史工具调用及结果保留原样。

融合成功时取代旧的 system 拼接/转 user 结果，自动加入 AGY 基础模块，不要求另开旧注入开关。若旧开关把原 system 放到 user，融合成功后移除的是网关添加的那条指导，不删除用户消息。失败、超时、输出为空、输出截断或结构不合法时，沿用已有开关处理后的原请求，避免阻断主请求。

模型被要求保留权限、审批、工具协议、项目规范和字面约束，合并重复表述；这不是语义等价证明，仍可能发生改写失真。建议先单账号试用并验证实际工具工作流。该功能用于提示词兼容，不保证任何第三方检测结果。

## 缓存和用量

- 缓存固定有效期 **24 小时**，从成功生成开始计算；命中不续期。
- 缓存键包含账号、调用方 API Key ID、文本模型、原系统指导、工具定义及 toolConfig、AGY 基础内容、网关前置文本、优化器规则和版本。任一项变更均重新生成。
- 不剥离系统提示里的动态字段：动态时间、项目路径等变化会导致缓存未命中，避免把不同含义的指导当成同一个输入。
- 缓存位于凭证目录的 `prompt_fusion_cache.sqlite3`，权限 0600，重启后保留。仅存哈希键和融合输出，不单独保存原输入；融合输出可能含项目路径或原提示里的敏感信息。
- 最多保留 128 条，每条输出不超过 128 KiB；容量满时先淘汰较早结果，可能早于 24 小时淘汰。过期记录在后续缓存访问时清理。
- 同进程共享正在生成的任务；共享同一个凭证目录的多进程通过 SQLite 租约避免同时生成。等待者取消不取消共享优化。跨进程等待最多约 55 秒，优化任务最多约 50 秒；失败后当前进程短暂退避 60 秒。进程崩溃后的租约最长 65 秒自动失效。
- 最多同时处理 32 个不同优化输入，超出时回退原请求。不同数据库/独立实例不共享缓存与租约。
- 优化调用使用真实模型额度，按调用方记入计费记录，`task_type=prompt_optimization`；命中缓存不新增优化调用。首次请求可能明显变慢。
- 默认请求采集功能若开启，仍按其独立配置采集上游请求；这里的缓存约束不替代采集保留设置。

配置存储键为 `prompt_fusion_enabled`（布尔）与 `prompt_fusion_accounts`（凭证文件名到 `inherit/on/off` 的映射），通过已认证的 `/config/get`、`/config/save` 管理。
